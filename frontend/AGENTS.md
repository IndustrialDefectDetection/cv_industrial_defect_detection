# Project Overview

This repository contains the Next.js frontend for the Industrial Defect Detection project.

The frontend will provide:
- A chatbot-style interface for collecting defect information
- Defect and machine dashboards
- Root-cause analysis report views
- Ticket and defect history views

# Tech Stack

- Next.js with App Router
- TypeScript
- Tailwind CSS
- ESLint
